# User Guide

ICE combines a desktop application, a headless CLI, Python automation, and
agent-facing tools on one project model. This guide is task-oriented: each page
shows how to use a surface from the user's point of view.

If you are building ICE from source, extending it, or working on the core, use
the {doc}`/developer/index` instead.
